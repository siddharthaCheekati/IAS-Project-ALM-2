THREAT ENCYCLOPEDIA

Understand the signal.

Know the behaviors behind your alerts, and the controls that reduce risk.

MALWARE / VIRUS

File infector

Attaches malicious code to executable files. Running an infected host file can activate the virus and spread it to other files.

Countermeasures

Use trusted software sources, application allowlisting, endpoint protection, and offline backups.

MALWARE / VIRUS

Boot-sector virus

Targets boot records or boot-related storage. It can execute early in startup and historically spread through infected removable media.

Countermeasures

Use Secure Boot where supported, restrict untrusted boot media, and recover from known-good installation media.

MALWARE / WORM

Network & email worms

Worms self-propagate between systems. Network worms exploit vulnerable services; email worms spread through messages or attachments.

Countermeasures

Patch exposed services, segment networks, filter attachments, and restrict unnecessary outbound connections.

INTRUSION / IDENTITY

Intruders & login abuse

Masqueraders use stolen identities; insiders misuse legitimate access. Repeated failed logins can indicate credential guessing, but can also be mistakes.

Countermeasures

Use MFA, least privilege, rate limits, and audit logs. Correlate alerts before concluding that an intrusion occurred.

DETECTION / KNOWN PATTERNS

Rule-based IDS

This lab flags five failed SSH logins from one IP within 60 seconds, Telnet traffic, and scans of at least ten ports. Rules are interpretable but can miss new patterns.

DETECTION / BASELINES

Statistical anomaly detection

Compares each traffic count to the previous 20 samples. Values above mean + 3 standard deviations trigger an alert. A floor of 1 on standard deviation avoids a zero-variance threshold.

Unusual activity is not always malicious. Baseline drift and false positives require investigation.
