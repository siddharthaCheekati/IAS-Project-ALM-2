Compare ESP transport and tunnel modes. Explore which fields are encrypted and integrity-protected.

ESP packet explorer

Green blocks: encrypted
Purple underline: integrity-protected (when ESP integrity is enabled)
Outer IP headers remain visible for routing. ESP's authentication tag is not included in its own integrity calculation.

Transport mode

Protects the IP payload between endpoints. The original IP header remains outside ESP and is not encrypted.

Tunnel mode

Wraps the complete original packet in ESP and adds a new outer IP header. Commonly used between VPN gateways.
