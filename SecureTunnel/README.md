# SecureTunnel

An independent local website in the ALM-2-Projects collection.

## Run this website

Install Python 3.10 or later, then run these commands inside this folder:

    python -m pip install -r requirements.txt
    python app.py

To start all three websites together, use Start-Websites.bat in the parent folder.
See the parent README.md for features and implementation notes.

Keep app.py, app.js, index.html, style.css, and requirements.txt together in this folder.
